# 本地开发连接配置

状态：持续维护；参数对应服务器 `/etc/learning-platform/learning-platform.env`，真实密码只在服务器读取，不写入本文件。

这份文档在 SSH 隧道建立后使用，讲 Navicat、Redis 客户端、MinIO 控制台怎么填连接参数。
隧道怎么建立、本地端口怎么验证，先看 [02-连接服务器.md](02-连接服务器.md)；服务器上各服务的
部署细节看 [01-服务器Docker教学清单.md](01-服务器Docker教学清单.md)。

## 1. 前提

- SSH 隧道已运行，本地四个端口测试通过（见 02-连接服务器.md 第 4、5 节）。
- 真实密码只存在于服务器，本地不保存、不写进 Git。

## 2. 密码从哪里读

SSH 登录服务器后查看：

```bash
cat /etc/learning-platform/learning-platform.env
```

各服务的用户名固定，密码对应不同变量：

| 服务 | 用户名 | 密码变量 |
| --- | --- | --- |
| MySQL | `lp_dev` | `MYSQL_APP_PASSWORD` |
| Redis | 无用户名 | `REDIS_PASSWORD` |
| MinIO | `lpminioadmin` | `MINIO_ROOT_PASSWORD` |

MinIO 用户名 `lpminioadmin` 由 generate-env.sh 固定生成。真实密码不要写进 Git、聊天或文档。

## 3. Navicat 连接 MySQL

- 连接类型：MySQL
- 主机：`127.0.0.1`
- 端口：`13306`
- 用户名：`lp_dev`
- 密码：`MYSQL_APP_PASSWORD` 的值
- 数据库：连接后从 `iam`、`content`、`learning` 中选择

## 4. Another Redis Desktop Manager 连接 Redis

新建连接：

- 名称：任意，例如 `lp-server`
- 主机：`127.0.0.1`
- 端口：`16379`
- 用户名：留空
- 密码：`REDIS_PASSWORD` 的值

## 5. MinIO 控制台与登录

浏览器打开 `http://127.0.0.1:19001`：

- 用户名：`lpminioadmin`
- 密码：`MINIO_ROOT_PASSWORD` 的值

Java SDK 使用 API 地址 `http://127.0.0.1:19000`，控制台用 19001。

## 6. 验证

- Navicat 能看到 `iam`、`content`、`learning` 三个库。
- ARDM 能连接并看到 key 空间。
- MinIO 控制台能登录。
