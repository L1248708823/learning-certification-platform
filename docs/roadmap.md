# 版本路线图

本文档规划学习项目的版本演进，每个版本有明确的范围、触发条件和宿主场景。后置能力的正式触发以本文档和 AGENTS.md「阶段门槛与触发检查」为准。

## 首期：个人学习闭环（当前）

范围：注册登录、课程浏览、免费报名、学习、练习、完成证书、字典（课程分类场景）。

宿主：个人学习者。

规格：`docs/spec/0001-个人学习闭环.md`。

完成判定：spec 第十一章验收对照清单逐条核验通过。

## 第二期：管理后台与 Commerce

范围：管理后台（老师内容管理、管理员运营）、商品与订单支付（#9）、站内信、操作日志、报表导出、定时任务（@Scheduled，每日学习统计）、字典管理界面。

宿主与对应关系：后台基础功能不是散装存在的，各自挂在真实业务上。站内信随订单成功与证书发放的通知场景，操作日志随管理后台的写操作，报表导出随运营查看学习数据的需求，定时任务随报表的数据聚合，字典管理随运营加分类配题型的配置需求。

触发条件：首期验收通过后开始规划；引入商品售卖或订单支付时正式进入本版本（#9 解封）。

## 第三期：评估体系

范围：考试（#8）、认证项目、平台认证证书。

触发条件：练习闭环稳定后出现正式评估需求。

## 后续阶段

- 企业培训（#10）：组织学习需求出现时。
- AI 顾问（#11）：对应需求或学习目标出现时。
- 服务拆分与 Kubernetes（#12）：按 ADR 0006 触发条件评估，第一次抽取对象为 Content。
