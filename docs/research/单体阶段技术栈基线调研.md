# 单体阶段技术栈基线调研

## 研究范围

为在线教育与职业认证平台确定单体阶段的技术栈与工具链，记录每个关键选择的候选方案、选择理由、学习成本、验证方式和重新评估条件，为「首期模块化单体与微服务演进路线」决策票据提供事实基础。

访问日期：2026-08-05。

## 结论摘要

单体与微服务共享核心应用栈。Java、Spring Boot、Spring MVC、Spring Security、MyBatis、MySQL、Redis、React、Docker Compose 在单体阶段学会后，微服务阶段直接复用。单体阶段不引入 Gateway、注册中心、配置中心、消息队列等分布式连接件，它们是在应用层外面多套的一层壳，不会替换应用层的东西。

相比 Issue 5 基线的关键调整：

- Java 从 17 升到 21。
- Spring Boot 跟随当前最新稳定版 4.1 线，3.5 线已结束 OSS 支持，不作为新项目目标。
- Spring Cloud Gateway WebFlux 整体后置，React 直接访问单体应用。
- 认证授权保留 Spring Authorization Server、OAuth2/OIDC、JWT 加 JWKS，集成进 IAM 模块，标准协议学习价值不因进程边界而损失。
- 补充测试栈、Lombok、Springdoc、Flyway、Bean Validation 和前端工程化。

## 选择原则

1. 主流性优先。优先国内就业市场的主流方案，同时兼顾国际主流，避免学习已停止维护或非主流的技术。
2. 学习价值优先。标准协议和通用概念优先于特定产品，例如 OAuth2/OIDC 优先于某个具体实现。
3. 主流程收敛。主流程只保留一个方案，候选方案作为扩展实验，避免主流程技术分裂。
4. 可演进。选择要支持从单体平滑抽取到微服务，模块边界和数据所有权从第一天保留。

## 关键版本事实（2026-08）

- Spring Boot 4.1.0 为当前最新稳定版（2026-06 发布），官方推荐作为新项目目标；3.5 线的 OSS 支持已于 2026-06-30 结束。来源：HeroDevs 版本生命周期页面。
- Java 21 与 Java 25 是当前两个 LTS。Java 21 成熟、生态验证充分、提供虚拟线程，官方免费更新到 2026-09；Java 25 是最新 LTS，Ubuntu 26.04 已默认 OpenJDK 25。来源：Java 版本矩阵、OpenLogic 迁移指南。
- MyBatis-Plus 3.5.16 为最新版本，支持 Spring Boot 4，是国内使用最广的 ORM 增强框架。来源：MyBatis-Plus 与 Xbatis 对比文章。

## 主流程 A 与扩展 B 分层

A 层是单体阶段必备，即上面的选择项，解决把业务闭环写对写稳。B 层是微服务阶段扩展，解决简历和面试，后置到拆分阶段引入。

B 层清单：

- Spring Cloud Gateway WebFlux。
- Nacos 注册中心加配置中心，国内微服务事实标准，Eureka 已停止开发，不碰。
- OpenFeign 服务间调用。
- Sentinel 限流降级，国内主流。
- RocketMQ 或 Kafka 异步事件。
- Outbox 模式保证跨服务一致性。
- SkyWalking 或 Micrometer Tracing 链路追踪。
- Kubernetes 部署，门槛后评估。
- Keycloak 外部 IAM 对比实验。
- Spring Modulith 模块边界自动验证。
- Seata 分布式事务，只理解，不采用强一致方案，最终一致性优先。

## 工具链

IntelliJ IDEA 写后端，VS Code 写前端，Docker Desktop，Apifox 或 Postman 调试接口，DBeaver 或 MySQL Workbench 管数据库，Node LTS 加 Nvm 管前端运行时，Git 加 GitHub CLI 管版本和票据。

## 暂缓引入与触发条件

Gateway、注册中心、配置中心、消息队列、分布式事务、链路追踪、Kubernetes 全部后置。触发条件沿用 Issue 5 的既有门槛，服务抽取或明确运维压力出现时才评估，单体和微服务阶段共享的核心栈不做替换。

## 验证清单

- 单体应用可以一条命令或 IDE 一键启动。
- Compose 只启动 MySQL、Redis 等基础依赖。
- React 完成登录、报名、学习、练习的完整闭环。
- 后端测试通过，包含 Testcontainers 集成测试。
- Flyway 迁移脚本可重复执行。
- CI 构建、测试通过，main 分支保持绿色。
