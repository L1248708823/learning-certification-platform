构建：Maven

它在 Java 世界的角色就是你熟悉的 npm，pom.xml 就是 package.json。现在要懂三个概念：坐标（groupId / artifactId / version 三件套）、依赖声明、Maven Wrapper（固定 Maven 版本，团队和 CI 用同一个）。后面票据再学：生命周期细节、依赖 scope 的差异。

语言与运行时：Java 21

现在要懂：JDK 是编译器加运行时，JAVA_HOME 决定命令行用哪个 JDK，程序从 main 方法开始跑。你不需要懂语言语法细节，后续写业务代码时自然会学。后面票据再学：虚拟线程、集合新特性。

框架：Spring Boot

现在要懂三个概念：starter（一包到位，相当于预装好的一组 npm 依赖）、自动配置（依赖在手，配置自动生成）、Actuator（健康检查端点，验证应用活着）。主类上的 @SpringBootApplication 记住"它是入口兼配置开关"就行。后面票据再学：Spring MVC 控制器、依赖注入、Spring Security。

数据库版本控制：Flyway

现在要懂：迁移脚本是数据库的 git（理由见学习记录 0002）、flyway_schema_history 是已执行记录表、V1 基线是空迁移、三库由 Compose 建而表由迁移脚本建。后面票据再学：ALTER TABLE 类迁移、baseline 衔接、校验失败的处理。

容器：Docker 与 Compose

现在要懂：容器是打包好的运行环境，解决"你机器能跑我机器跑不了"；镜像是一份只读模板，容器是它的一个运行实例；Compose 用 YAML 一次性编排多个容器，本项目的 MySQL / Redis / MinIO 都在里面。为什么应用本体不打包进 Compose，是教学决定，见调研文档验证清单。后面票据再学：Dockerfile、镜像构建、多阶段构建。

日志：SLF4J + Logback

现在要懂：日志级别（INFO 是常规、ERROR 是出错）、pattern 是每行日志的格式模板、滚动文件防止日志无限膨胀。后面票据再学：链路追踪日志、结构化日志。

测试：这个项目怎么测

现在要懂：冒烟测试（上下文能组装起来就通过）、它故意不需要 Docker（排除数据源自动配置）。后面票据再学（重点预告）：单元测试 JUnit 5、Mockito 打桩、AssertJ 断言、Testcontainers 起真容器做集成测试、TDD 先写测试再写实现，这些从首期-02 开始逐个出现。

工程与配置：杂项

现在要懂：application.yml 是配置中心、端口冲突怎么查、.gitignore 和 .gitattributes 管什么。后面票据再学：多环境 profile、配置加密、配置中心（那是微服务阶段的事）。

现在不用焦虑的清单

以下全部是后面票据或后置能力的事，遇到名字不认识完全正常：Spring Security 和 OAuth2（首期-03）、Redis 用法（首期-03）、MyBatis 全家桶（首期-03 起）、Testcontainers 集成测试（首期-02 起）、MinIO 文件上传（首期-04）、React 前端（首期-08）、CI 流水线（首期-09）、微服务和 Kubernetes（后置能力，触发条件见 AGENTS.md）。
