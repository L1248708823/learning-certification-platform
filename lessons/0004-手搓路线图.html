LESSON 0004

手搓路线图：从零到首期验收

一张完整地图：手搓工程骨架的每一步做什么、用什么命令、做完的标志是什么。看完你应该能说出"我现在在哪，下一步做什么"。

本课目标

七步走完整个工程骨架。每一步都有明确的验证点，验证点出现才算做完。你不需要一次走完，但每一步都可以单独停、单独问。

地图总览

  1. 建目录骨架，零依赖，立刻有第一个胜利。
  2. 写 pom.xml，读懂每个依赖。
  3. 装 JDK 21，让 Maven 跑起来，听到第一声 BUILD SUCCESS。
  4. 写主类、配置、迁移脚本、测试，mvn test 全绿。
  5. 装 Docker，compose 起三个依赖容器。
  6. 启动应用，健康检查 UP，数据库三库就位。
  7. 提交 git，收尾。

第一步：建目录骨架

在项目根目录执行（git bash）：

mkdir -p backend/src/main/java/com/learningplatform
mkdir -p backend/src/main/resources/db/migration
mkdir -p backend/src/test/java/com/learningplatform
mkdir -p deploy/mysql/init

验证点：ls 能看到上面四层目录都在。这一步不需要装任何东西，先获得掌控感。

卡住怎么办：路径写错就删了重来，目录操作零风险。

第二步：写 pom.xml

在 backend/ 下新建 pom.xml。照抄已提交的版本可以，但每段都要能解释：parent 是版本事实，java.version 是 21，五个依赖各自管什么（web、actuator、flyway-core、flyway-mysql、mysql 驱动）。

验证点：你能不看注释说清每个依赖的作用。记不住的打开 手搓速查 对着讲。

卡住怎么办：先抄后懂，这一课的目标是"认识"，下一票才是"默写"。

第三步：装 JDK 21，让 Maven 跑起来

winget install BellSoft.LibericaJDK.21，把 JAVA_HOME 指到 21，新开终端确认 java -version 显示 21。然后在 backend/ 下执行 ./mvnw validate。

验证点：输出以 BUILD SUCCESS 结束。这是整个工程的第一声"通了"。

卡住怎么办：java -version 还是 17，说明 JAVA_HOME 没生效，新开终端再试；报 mvnw 找不到，先确认在 backend/ 目录里。

第四步：写主类、配置、迁移脚本、测试

五个文件，五个意图：主类（入口）、application.yml（数据源指 iam、Flyway 开关、Actuator 暴露）、logback-spring.xml（日志格式）、V1__baseline.sql（基线迁移）、测试类（冒烟，不需要 Docker）。

验证点：./mvnw test 全绿。这个测试特意排除数据源自动配置，所以没装 Docker 也能过。

卡住怎么办：测试报错看堆栈第一行，通常是类名或配置键拼错。

第五步：装 Docker，起三个依赖

安装 Docker Desktop 并启用 WSL2 后端。在项目根目录执行 docker compose up -d。

验证点：docker compose ps 三个容器都是 healthy。MySQL 首次启动要跑初始化脚本，等 health 变绿是正常的。

卡住怎么办：起不来先看日志 docker compose logs mysql，端口被占用就在 compose.yaml 改宿主机端口映射。

第六步：启动应用，验证三库

cd backend 后执行 ./mvnw spring-boot:run，看到 Tomcat started on port 8080。浏览器开 http://localhost:8080/actuator/health。

验证点：health 返回 status UP。再用 DBeaver 连 localhost:3306，看到 iam / content / learning 三库，iam 里有 flyway_schema_history。

卡住怎么办：连接失败先看 MySQL 容器日志，确认密码和 iam 库存在。

第七步：提交 git，收尾

git add -A，git commit，确认工作树干净。全部验证点重新过一遍。

验证点：git log 能看到你的提交，git status 干净。

地图使用三原则

  1. 验证点优先：代码写多少都算不了完成，验证点出现才算。
  2. 卡住先查速查：手搓速查 里有常见问题和解法，查完再问老师。
  3. 环境装到需要时：头两步不需要装任何东西，第一个小胜利来得越早越好。
