首期-01 术语表

第一个票据涉及的全部术语，扫一遍给不懂的打勾，配合第五课使用。标注"后续"的现在不用学。

构建：Maven

术语一句话解释何时用
MavenJava 世界的构建工具，相当于 npm 加构建脚本本票据
pom.xml项目配置文件，相当于 package.json本票据
坐标groupId / artifactId / version 三件套，唯一标识一个包本票据
parent继承父 pom，版本号等事实由 Spring Boot 统一托管本票据
依赖声明dependency 块声明要用的库，scope 控制使用范围本票据
Maven Wrappermvnw 脚本，固定 Maven 版本，团队和 CI 用同一个本票据
生命周期validate 到 install 的阶段序列，validate 只校验 pom本票据

语言与运行时：Java

术语一句话解释何时用
JDKJava 开发工具包，含编译器和运行时本票据
JAVA_HOME环境变量，决定命令行工具用哪个 JDK本票据
main 方法程序入口，JVM 从它开始执行本票据
LTS长期支持版本，Java 17 / 21 / 25 是近年三档本票据
虚拟线程Java 21 起的轻量级线程，高并发 IO 利器后续

框架：Spring Boot

术语一句话解释何时用
Spring Boot让 Spring 应用快速启动的框架，约定大于配置本票据
starter一组预打包依赖，加一个就配好一类能力本票据
自动配置依赖在手，Spring 自动生成对应组件本票据
@SpringBootApplication主类注解，入口加配置开关本票据
application.yml集中配置：数据源、Flyway、Actuator 等本票据
Actuator监控端点模块，health 验证应用是否活着本票据
内嵌服务器Tomcat 打进应用里，无需单独装 Web 服务器本票据
Spring MVCWeb 层框架，写接口的控制器就靠它后续
依赖注入Spring 管理对象创建与装配的机制后续

数据库版本控制：Flyway

术语一句话解释何时用
Flyway数据库迁移工具，数据库的 git本票据
迁移脚本db/migration 下的版本化 SQL 文件，V1 起编号本票据
flyway_schema_history已执行迁移的记录表，落在 iam 库本票据
基线空迁移 V1，只建立版本控制起点本票据
全限定表名schema.表名 的写法，跨库访问的基础本票据
schemaMySQL 里的逻辑库，本项目的模块边界本票据
ALTER TABLE改表结构的迁移，后续票据第一次遇到后续

Docker容器技术，打包运行环境，解决环境不一致本票据

healthcheck容器内自检命令，Compose 据此报告健康状态本票据
