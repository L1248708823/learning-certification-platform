远程服务器变体（本机不装 Docker）

动作命令说明
服务器装 Docker发行版包管理器，或 curl -fsSL https://get.docker.com | sh加 compose 插件，启用服务
服务器拉代码git clone 仓库，cd 到根目录compose.yaml 和 deploy/ 都在仓库里
服务器起依赖docker compose up -d端口只绑 127.0.0.1，公网不可见
本机建隧道ssh -L 3306:127.0.0.1:3306 用户@服务器 -N窗口保持开着，应用照常连 localhost
验证本机 DBeaver 连 localhost:3306看到三库即隧道通
后续集成测试DOCKER_HOST=ssh://用户@服务器Testcontainers 起远程容器，首期-02 起

安全要点：安全组只开 SSH；Redis / MinIO 的隧道用到时再开；服务器上不要裸开 2375 远程 API 端口。

常见问题

现象原因解法
java -version 还是 17JAVA_HOME 未生效新开终端；确认环境变量指向 JDK 21 目录
compose 起不来端口被占用或镜像拉取慢docker compose logs 看原因；改 compose 端口映射；配置镜像加速
MySQL 容器反复重启初始化脚本报错或数据卷残留docker compose logs mysql；docker compose down -v 清数据卷重来
应用启动连不上数据库MySQL 未健康或密码不符先 docker compose ps 确认 healthy，再核对 application.yml 密码
health 返回 DOWN数据库连接问题打开 show-details 查看 db 组件详情，或看应用日志堆栈
mvn test 失败类名、配置键拼错看堆栈第一行，对照速查表文件职责
