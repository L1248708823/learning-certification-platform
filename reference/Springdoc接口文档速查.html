Springdoc 接口文档速查

先区分自动生成的信息和需要人工补充的信息，再决定注解放在哪里。

生成链路

@GetMapping / @PostMapping + DTO + @Valid
                    ↓
             Springdoc 运行时扫描
                    ↓
      /v3/api-docs 和 /v3/api-docs.yaml
                    ↓
          /swagger-ui/index.html

注解职责

注解放置位置适用信息
@TagController 类业务分组
@OperationController 方法调用目的、业务时限、重要前提
@ApiResponsesController 方法真实 HTTP 状态码和业务错误码
@Schema公开 DTO 字段、响应字段字段语义、示例、枚举编码、只读或只写
@Parameter路径参数或查询参数参数语义和示例
@HiddenController 或方法不属于调用方目录的内部入口

当前项目入口

地址用途
http://localhost:8080/swagger-ui/index.html查看文档和人工试调接口
http://localhost:8080/v3/api-docs查看机器可读的 OpenAPI JSON
http://localhost:8080/v3/api-docs.yaml查看 YAML 格式，可供其他工具导入

排查顺序

  1. Swagger UI 404：检查 pom 是否有 springdoc-openapi-starter-webmvc-ui，随后 Maven Reload。
  2. UI 能打开但没有接口：检查 Controller 是否被 Spring 扫描，是否带 @Hidden，以及条件装配属性是否关闭。
  3. 字段说明不足：先看 Bean Validation 能否表达，业务语义再补 @Schema。
  4. 页面显示的状态码不完整：补 @ApiResponses，只列真实会发生的业务错误。
  5. 手工调用失败：先看 HTTP 响应。数据库、Redis、验证码和认证失败属于业务运行问题，不是 Swagger UI 故障。

生产边界

本地学习环境可开放文档端点。生产环境应按访问策略关闭或保护 /v3/api-docs 与 /swagger-ui/**，避免不必要地公开内部接口结构。
